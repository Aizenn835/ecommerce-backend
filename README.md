# E-Commerce Backend

A RESTful backend API for an e-commerce application built with Spring Boot.

## 🚀 Features

- User Registration
- User Login
- JWT Authentication
- Product Management
- Shopping Cart
- Image Upload
- PostgreSQL Database
- Spring Security
- REST API

## 🛠️ Technologies

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- JWT
- Lombok

## 📁 Project Structure

```
src/
 ├── controller/
 ├── service/
 ├── repository/
 ├── entity/
 ├── dto/
 ├── security/
 ├── exception/
 └── config/
```

## ⚙️ Setup

1. Clone the repository

```bash
git clone https://github.com/Aizenn835/ecommerce-backend.git
```

2. Configure your database.

3. Set the required environment variables:

```
DB_USERNAME
DB_PASSWORD
JWT_SIGNING_KEY
```

4. Run the application.
